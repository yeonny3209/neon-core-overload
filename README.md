# 네온 코어 디펜스: 오버로드

> 5분 만에 한 판, 그런데 멈출 수 없다.

「네온 코어 디펜스」의 후속작. 네온 세계를 그대로 이어받아, 화려한 연출과 "한 판만 더" 하게 되는 중독성에 집중한 2D 타워 디펜스입니다.

## 특징

- **방어탑 20종 × 갈래 진화** — LV3까지 강화한 뒤 A 또는 B로 진화 (40가지 모습)
- **캠페인 3챕터 18스테이지** — 별 3개 도전 조건, 클리어할 때마다 새 방어탑 해금
- **거대 보스 3종** — 기가 크러셔 · 하이브 마더 · 오버로드, 3단계 패턴과 약점
- **사령관 스킬 5종** — 궤도 폭격 · 시간 동결 · 오버클럭 · 긴급 수리 · 에너지 서지
- **지형 효과 6종** — 에너지 칸 · 가속 패드 · 전자기장 · 냉각수 · 정전 · 움직이는 에너지 칸
- **아수라장** — 끝없이 강해지는 적, 3웨이브마다 고르는 증강 120종
- **하드 모드**, 내 기록, 방어탑 도감, 결과 카드 저장
- 터치 · 마우스 모두 지원, 웹과 안드로이드 앱

## 만들기

```bash
python build.py --check
```

`src/`의 조각을 하나로 합쳐 `index.html`을 만듭니다. 웹 · 안드로이드 앱 모두 이 파일 하나를 씁니다.

| 파일 | 내용 |
| --- | --- |
| `src/00-core.js` | 공통 도구, 저장 |
| `src/01-audio.js` | 효과음, 배경음악 |
| `src/02-towers.js` | 방어탑 20종과 진화 |
| `src/03-enemies.js` | 적 14종, 거대 보스 3종 |
| `src/04-stages.js` | 맵, 18스테이지, 웨이브 |
| `src/05-skills-augs.js` | 사령관 스킬, 증강 120종 |
| `src/10-state.js` ~ `14-skills.js` | 게임 규칙 |
| `src/20-art.js`, `21-render.js` | 그림, 화면 그리기 |
| `src/30-ui.js` ~ `40-main.js` | 화면, 입력, 튜토리얼, 메인 루프 |

안드로이드 APK는 `main`에 올리면 GitHub Actions가 자동으로 만들어 `android-latest` 릴리스에 올립니다.
